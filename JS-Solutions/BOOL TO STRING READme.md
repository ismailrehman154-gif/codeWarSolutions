Complete the method that takes a boolean value and return a "Yes" string for true, or a "No" string for false.

Fundamentals

This function uses a ternary operator to check the boolean value. If the value is true, it returns "Yes". If the value is false, it returns "No".

bool is the condition being checked.
? "Yes" means return "Yes" if bool is true.
: "No" means return "No" if bool is false.
