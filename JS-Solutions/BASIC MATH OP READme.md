# Basic Math Operations

This project has a function that can do four basic math operations:

* Add
* Subtract
* Multiply
* Divide

The function takes:

1. An operator like `+`, `-`, `*`, or `/`
2. A first number
3. A second number

Example:

```js
basicOp('+', 4, 7)
```

This returns:

```js
11
```

The goal of this project was to practice using functions and conditional statements in JavaScript.
